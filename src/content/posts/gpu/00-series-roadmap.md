## 系列目标

建立一套从硬件直觉到代码实验的 GPU 学习笔记。先理解并行执行和内存访问，再通过小型 kernel、基准测试和性能分析验证假设。具体 API 与结论会注明硬件、驱动、编译器和工具版本。

## 学习路线

1. GPU 用途与并行计算基本概念
2. GPU 架构概览：计算单元、线程束与执行模型
3. SIMT、数据并行与线程映射
4. 内存层次：全局、共享、缓存与寄存器
5. 内存合并、带宽与访问模式
6. 用 CUDA 编写并运行第一个 kernel
7. 线程块、网格与索引计算
8. 分支分歧、占用率与资源限制
9. 规约、矩阵乘法等常见并行模式
10. 正确性检查、基准测试与性能剖析
11. 共享内存、异步操作与优化案例
12. 多 GPU 与数据传输开销
13. 对比不同 GPU 编程模型与可移植方案
14. 完成一个端到端 GPU 小项目

## 实验约定

- 每次性能比较记录 GPU 型号、驱动、编译器、库版本和运行参数。
- 先验证结果正确，再报告性能；注明预热、重复次数和计时方式。
- 使用可复现的输入规模，并对比 CPU 或简单 GPU 基线。
- 区分理论带宽/峰值与实际测量结果，不把单次测量当作结论。
